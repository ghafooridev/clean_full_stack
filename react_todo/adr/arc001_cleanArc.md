## context
investigae the best way and patterns and architecture to implement the whole TODO app project

## decision
using clean architecture with standard pattern (domain-application-infra-presentation) to implement app

## consequenses
### pros
1- clean and modern
2- separate the concerns
3- using port adaptor pattern 
### cons
1- complexity is higher than other structure
2- lack of exprience
3- some boundaries are mixed in frontend project

## alternative
-feature based (FDA)
-dock model
-atomic design
